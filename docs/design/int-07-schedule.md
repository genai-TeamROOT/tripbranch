# INT-07: SCHEDULE

## 문서 정보

| 항목 | 값 |
| --- | --- |
| 버전 | v0.1 |
| 상태 | 1차 구현 진행 — Intent 분류·임시 안내만 완료 대상 |
| 최종 수정 | 2026-08-06 |

## 1. 목적

여러 장소의 방문 순서와 시간 배분이 필요한 요청을 단일 장소 추천(`RECOMMEND`)과
구분한다. 예: “오늘 오후 일정 짜줘”, “반나절 코스 만들어줘”, “어디부터 갈지 순서 알려줘”.

## 2. 1차 구현 범위

- A의 1단계 Intent 분류에서 `SCHEDULE`을 반환한다.
- 아직 조건 추출, C 후보 조회, D의 상위 10개 요청, 일정 편성 LLM 호출, B 이력 기록은 하지 않는다.
- 현재 응답은 `"일정 추천 기능은 아직 준비 중이에요."`로 안전하게 종료한다.

이 단계는 일정 요청이 기존 `RECOMMEND`로 오분류되어 단일 장소 추천으로 처리되는 것을
막기 위한 분류 단계다.

## 3. 후속 구현 경계

후속 단계에서만 `UserConditions` 기반 후보 수집, D 추천 결과, 후보 간 거리, 일정 편성
LLM 출력과 일정에 포함된 장소의 B 이력 기록을 연결한다. 후보 수를 5개에서 10개로
확장하는 정책과 혼잡도 2차 Scoring의 관계는 D 협의 후 결정한다.

## 4. 판별 경계

| 발화 | Intent |
| --- | --- |
| “오늘 오후 종로 반나절 코스 짜줘” | `SCHEDULE` |
| “경복궁, 인사동 가고 싶은데 어디부터 갈까?” | `SCHEDULE` |
| “오늘 갈 만한 곳 추천해줘” | `RECOMMEND` |
| “경복궁 오늘 열어?” | `INFO` |
| “다른 곳 보여줘” | 이전 추천 이력이 있을 때 `MODIFY` |
